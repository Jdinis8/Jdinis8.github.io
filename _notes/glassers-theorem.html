Statement of the Theorem

Glasser's Master Theorem[1] is a generalization of an older theorem by Cauchy, that says \[ \int_{-\infty}^{+\infty} f\left(1-\frac{1}{x}\right)dx = \int_{-\infty}^{+\infty} f(x) dx\,, \]

where $f(\cdot)$ is an integrable function and all the integrals imply the Cauchy principal value. This meaning that if $f(\cdot)$ blows up at some $x$, we should try to see if this blow up cancels on either side of the integral. In other words, the Cauchy principal value is defined as

\[ \text{P.V.} \int_a^b f(x) dx= \lim_{\epsilon\rightarrow 0^+}\left[\int_a^{c-\epsilon}f(x)dx + \int_{c+\epsilon}^b f(x)dx \right] \]

Glasser's theorem states then that,

\[ \int_{-\infty}^{+\infty} f\left(x - \sum_{j=1}^{n-1}\frac{a_j}{x-C_j}\right) dx = \int_{-\infty}^{+\infty} f(x)dx \]

Proof of Cauchy's Theorem

To prove \[ \int_{-\infty}^{+\infty} f\left(1-\frac{1}{x}\right)dx = \int_{-\infty}^{+\infty} f(x) dx\,, \] let's first do a substitution, $u = x - \frac{1}{x}$. Solving this for $x$ we get \[ x^2 - u x - 1 = 0 \iff x = \frac{1}{2}\left(u \pm \sqrt{u^2 + 4} \right)\,. \] Now, notice that either solution to $x$ will either be strictly non-negative or strictly non-positive, because the sign is completely dominated by the square root. However, if we separate the original integral as \[ \int_{-\infty}^{+\infty} f\left(1-\frac{1}{x}\right) dx = \int_{-\infty}^{0} f\left(1-\frac{1}{x}\right) dx + \int_{0}^{+\infty} f\left(1-\frac{1}{x}\right) dx \,, \] then we just need to choose the appropriate root for each integral. Before we substitute, note also that \[ dx = \frac{1}{2}\left(1 \pm \frac{u}{\sqrt{u^2+4}}\right)du\,, \] and we still need to calculate the limits of the integrals. These can be summed up as follows, \[ \lim_{x\rightarrow 0^+} u = -\infty \quad \lim_{x\rightarrow 0^-} u = +\infty\\ \lim_{x\rightarrow +\infty} u = +\infty \quad \lim_{x\rightarrow -\infty} u = -\infty \] Thus, \[ \int_{-\infty}^{0} f\left(1-\frac{1}{x}\right) dx + \int_{0}^{+\infty} f\left(1-\frac{1}{x}\right) dx =\\ \frac{1}{2}\left[\int_{-\infty}^{+\infty} f(u) \left(1 - \frac{u}{\sqrt{u^2+4}}\right)du + \int_{-\infty}^{+\infty} f(u) \left(1 + \frac{u}{\sqrt{u^2+4}}\right)du\right] \,. \] But notice that the domains of integration under the change of variables suddenly becomes the same! This means that we can collect everything under the same integral. \[ \frac{1}{2}\left[\int_{-\infty}^{+\infty} f(u) \left(1 - \frac{u}{\sqrt{u^2+4}}\right)+ f(u) \left(1 + \frac{u}{\sqrt{u^2+4}}\right)du\right] = \int_{-\infty}^{+\infty} f(u) du\,. \]

Proof of Glasser's Theorem

In a similar spirit to what we did with Cauchy's theorem, we do a change of variable, \[ x - \sum_{j=1}^{n-1}\frac{a_j}{x-C_j} = u\,. \] Let's get rid of the numerators first, \[ \prod_{k=1}^{n-1}\left(x-C_k \right)\left[ x - \sum_{j=1}^{n-1}\frac{a_j}{x-C_j} \right] = u\,\prod_{k=1}^{n-1}\left(x-C_k \right) \] We will now write the coefficients of $x^n$ and $x^{n-1}$, for reasons that will become apparent in a second, \[ x^n - x^{n-1}\left(u - \sum_{k=1}^{n-1}C_k\right) + (\dots) = 0\,. \] This is an $n$-degree polynomial and therefore it has $n$ roots. The roots are all different because we take the $C_k$'s to be all different. This fact tells us that the above polynomial can also be written in terms of its roots, $x_i(u)$, as follows \[ (x - x_1(u))(x - x_2(u))(\dots)(x - x_n(u)) = x^n - x^{n-1}\left( \sum_{i=1}^n x_i(u) \right) + (\dots) = 0\,. \] This allows us to identify \[ \sum_{i=1}^n x_i(u) = u - \sum_{k=1}^{n-1}C_k\implies \sum_{i=1}^n x_i^\prime(u) = 1 \] Still to be finished
